  marker: plain

  => PDF viewer 渲染: NO ❌

  marker: S2
  => PDF viewer 渲染: NO ❌

=== S3: nimbus-doc:// PDF iframe (plugins:true) ===
  frames: [
  "nimbus-doc://nimbus-doc-test.pdf/"
]
  marker: S3
  => PDF viewer 渲染: NO ❌

=== S4: loadURL(nimbus-doc://pdf) 顶层 ===
  => PDF viewer 渲染: NO ❌

================ 汇总 ================
S1 (file 顶层): false | S1b (loadURL file): false | S2 (file iframe): false | S3 (custom iframe): false | S4 (custom 顶层): false
结论: iframe 可行 = false ; 自定义协议可用 = false
